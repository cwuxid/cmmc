# Bailey Motion Engine implementations

- [Bailey_Motion_Engine/](Bailey_Motion_Engine/README.md): original JavaScript source project; open its `index.html` for the browser interface.
- [Bailey_Motion_Engine_Python/](Bailey_Motion_Engine_Python/README.md): Python engine with the supplied two-plan/barrier/stair geometry, plus an archived legacy layout for original-port comparisons.

These are separate implementations of the Bailey auditorium model. The older abstract square-room implementations remain at `../python/` and `../javascript/`.

For launch commands, a desktop walkthrough, parameter editing, exports, and troubleshooting, start with the [Python how-to](Bailey_Motion_Engine_Python/README.md#how-to-run-your-first-experiment).
